# Sign-offs
# Before any deliverable reaches the Owner, all these must be checked.
# Format: [YYYY-MM-DD HH:MM:SS] [ROLE] — SIGN_OFF — [deliverable] — [APPROVED / REJECTED: reason]

## Sign-off checklist (required before every release)
- [ ] Security sign-off — Director of Security
- [ ] QA sign-off — Director of QA
- [ ] Deployment stable — Director of DevOps
- [ ] Documentation complete — Technical Writer
- [ ] Guide summary ready — Guide & Explainer

---

## High-stakes dual sign-off (mandatory)
For any change that is pushed to a live/public system, deletes data, or is security-sensitive:
Director of Security AND Director of QA must BOTH sign off here (in parallel) before release.
Routine low-risk changes follow the standard single-chain checklist above.
